# Tidelands — Ransom Note (baseline)

Tutorial site in the "Tidelands Ransom Note" design system. This is the control: reproduce the current look.

## Design system tokens
- Surfaces: warm cream paper `#e5e2da` page, white `#fff` cards, near-black `#141313` top bar.
- Ink `#000`; flag accent salmon `#ffb4ab`; holographic foil gradient (pink `#ff9ad5` → lilac `#c7a6ff` → sky `#8fd3ff` → mint `#9dffcf` → lemon `#fff59a` → peach `#ffb38a`) used sparingly for the logo sticker and the callout's label strip.
- Typography: body Noto Serif 17/30; headings Space Grotesk 700, plain (not cut-out); labels, table headers and buttons in Space Mono caps with 0.1em tracking.
- Shape: square corners everywhere, 2px black borders, hard offset shadows (5px 5px 0) with no blur. The CTA is a black slab with cream text and a salmon hard shadow, rotated -1deg like a pasted clipping. The logo is a die-cut round holographic sticker tilted -8deg.
- The wordmark "Tidelands" in the top bar is the one place with ransom-note letters: each letter a different cut-out clipping (mixed fonts, tilts, black/white/foil tiles).
