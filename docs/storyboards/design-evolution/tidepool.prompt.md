# Tidelands — Tidepool

Tutorial site in a "Tidepool" design system: calm, organic, tidal; ripples and the whale-tail fluke as motifs.

## Design system tokens
- Surfaces: sea-foam paper `#f3f1ea`, sand `#e9e1cf` for the rail, deep tide `#12343b` for the top bar; cards `#fbfaf6`.
- Ink `#1d2b2f`; accents kelp green `#2f6f5e`, tide teal `#2c8c99`, coral `#e2725b` for errors; muted pearl iridescence (a very soft teal→lilac→sand gradient) only on the logo.
- Typography: headings Newsreader 600 (a warm serif display), H1 44px; body Literata 18/31; labels DM Sans 500 small caps.
- Details: section breaks are concentric ripple arcs (three thin rings fading outward) instead of horizontal rules. The H1 sits above a faint set of ripple rings spreading from the left margin. The logo's whale-tail fluke is echoed as a small fluke glyph used as the bullet marker for "Next steps". Rounded corners 14px, soft long shadows (0 12px 30px rgba(18,52,59,0.12)). The CTA is a pill in kelp green with a fluke icon. The callout is a sand-coloured card with a ripple corner ornament. Generous whitespace.
