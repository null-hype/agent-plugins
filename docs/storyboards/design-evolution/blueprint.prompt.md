# Tidelands — Blueprint

Tutorial site in a "Blueprint / cyanotype drafting" design system: the page is an engineering drawing sheet.

## Design system tokens
- Surfaces: cyanotype blue ground `#0f3b66`, slightly lighter panel `#164a7a`, rail `#0c3157`. A faint 24px drafting grid in `rgba(255,255,255,0.06)` with a stronger line every 5 cells.
- Linework: white `#f2f7ff` hairlines (1px) for every rule and border; dashed construction lines; small tick marks at section starts. Accent: drafting red `#ff6b5a` for errors and the diagnostic line; pale yellow `#ffe58a` for the active item and the CTA.
- Typography: headings IBM Plex Sans 600 in white; body IBM Plex Sans 400 16/28 in `#dbe7f5`; labels, dimensions and table headers IBM Plex Mono caps, 11px, tracking 0.12em.
- Details: the H1 carries dimension callouts (a thin arrowed line with a mono label like "68ch" spanning the measure). The page has a title block in the bottom-right corner like a drawing sheet: "SHEET 0 · START HERE · REV C · SCALE 1:1". The logo is drawn as white line art with faint construction circles behind it. The CTA is an outlined rectangle with corner ticks, filled pale yellow on hover. The callout is a dashed box with a mono "NOTE 1" tag. No shadows, no rounded corners, no gradients.
