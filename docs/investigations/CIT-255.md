The Part 4 replay is a **concept storyboard**, not a write-skew witness.
This implements the labeling recommendation in [CIT-255](https://linear.app/citizen6librarian6refrain4/issue/CIT-255/review-finds-no-valid-write-skew-vulnerability-evidence).
Existing lesson routes and frame identities remain stable for inbound links.

The relay reads Content-Length and forwards bytes, rather than normalizing
Transfer-Encoding. A Python image change does not upgrade Gunicorn installed from
the local codebase. The proposed “parsers re-agree” explanation is withdrawn.
The supplied fixed parser rejects gzip following chunked. These facts invalidate
the authored A/B mechanism; labeling it simulated would not make it technically
sound.

## Requirements before promoting this to an experiment

1. Find a viable interaction from a secure base. Define an independently checkable
   authorization invariant before constructing branch outcomes.
2. Give the harness an exact source-tree input. `Bootstrap()` currently clones
   upstream and returns success on successful exploitation. Preserve that exploit
   reproduction behavior; introduce a separate trusted security-invariant oracle
   whose success means blocking the tested bypass while retaining valid traffic.
3. Keep that oracle outside branch-writable inputs. Pin source commits, dependencies
   and image digests. Record tree identity, oracle identity, exit status, request
   observations and Dagger trace for every run. Harness errors are not security passes.
4. Require the identical oracle to pass on base, base+A and base+B, and fail on
   base+A+B after an actual conflict-free source merge. Generate this matrix from
   execution, retain artifacts and enforce it in CI before claiming a witness.
5. Add a benign non-overlapping pair and a same-line conflict pair. Check both
   merge orders, rebase and cherry-pick. Cover spacing, case, tabs, repeated headers,
   coding order and socket fragmentation with the same oracle version.
6. Capture agent/session provenance and common starting revision before attributing
   branches to concurrent agents. Seal predictions before execution; retain misses.

One witness establishes possibility only. N(N−1)/2 counts candidate pairs; it
is not an empirical vulnerability rate. Measuring a scaling claim needs a defined
sample and executed pairwise comparisons as N grows.

This change does not implement or claim that experiment. It also does not resolve
PR #97's historical divergence from main or remove unrelated commits from that PR.
Its scope is corrected presentation, immutable replay frames, consistent verdict
validation and regression coverage. Replay tests establish client behavior only.
