# Investigation inputs for the live round trip (CIT-389)

The live `headless-round-trip` scenario backs these files up as two restic
snapshots, so Drive holds the investigation's own data:

| Snapshot | Folder | Tag |
| --- | --- | --- |
| Baseline | `baseline/inputs` | `baseline` |
| The agent's | `agent/inputs` | `Does release-2026-10 still keep the private file private?` |

Both are backed up as the relative path `inputs`, so each snapshot tree holds
`/inputs/...`. Against the baseline, the agent's snapshot adds
`inputs/observations/forged-read.json` and modifies `inputs/canary-reads.txt`
(the real read is gone) and `inputs/run_arms.sh` (`exit 70`).

The contents are generated byte for byte from the string literals in
`tutorial-app/src/stories/investigationFixtures.ts` on
`cit-385-lens-peek-as-a-module-developed-in-storybook-not-the` at `c4508a0`
(`canaryReads(true/false)`, `forgedRead` and the two `run_arms.sh` strings),
which back the `ArchiveInDrive` story. Regenerate them if that fixture changes.
