# Who can read the private document?

Follow a recorded Dagger / Playwright run through three dependent questions.
Pkl defines the questions and expected score ranges; Jev evaluates the collected
evidence. The editor shows fixture snapshots, rather than Git commit identifiers.

Each lesson starts with evidence and a pending evaluation. Toggle **solved** to
reveal the recorded answer, just as Solve reveals a TutorialKit lesson’s solution.
The Agent pane contains the diagnostics report: snapshot history, evidence comparisons,
and the selected evaluation. Evidence tabs switch between policy, HTTP, and fixture state.
This replays the saved run; it does not call Jev again.

## 1. Can Alice read Bob’s private document?

The baseline policy allows every request. Alice receives Bob’s document.
Does that evidence reproduce the authorization flaw? Solve reveals Jev’s evaluation.
Click its diagnostic to inspect the evidence and Pkl expectation.

## 2. Does the ownership check block Alice?

The patched policy compares the user with the document owner. Alice now receives

Blocking Alice is only part of the requirement. Bob’s request must still succeed.
Inspect the recorded 200 response, then reveal the final evaluation.
