# Budget Authority — Proposal P against the budget

Part 3, one lesson per story. Each lesson opens on its starter state, which is the
previous lesson's solved state plus one incoming message. Toggle `solved` to replay
the recorded reply, as the lesson's **Solve** button does. Every frame is scripted
by `tests/budget-authority.tutorial.spec.ts`. Only the git merge (turn 2) and the
two budget evaluations (turns 3 and 5) are computed for real.

## 1. Jev types the answer

Solve turns **Type** from `malformed` to `well-formed`. **Budget** stays `not evaluated`.
