CIT-303 PR follow-up: parse trace evidence instead of substring-matching it

Review of PR #120 found the independent-read check still only did a
bare substring match on the retained trace text, and nothing required
valid trace evidence to exist for an arm whose expected open-count was
already zero -- so deleting a blocked arm's whole trace, or replacing
real evidence with a prose mention/failed EACCES open/different-directory
open, still passed with empty diagnostics. Reconcile.pkl now requires a
parsed, successful openat of the exact path, plus proof-of-capture (a
successful open of the arm's own source file) for every arm; run_arms.sh
collects trace text under the same criterion and no longer merges
strace's stderr with the script's own JSON stdout.
