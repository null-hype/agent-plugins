# Can the check tell a real read of the private file from a forged one?

A Rails app keeps a private file on its server, `/work/dummy-canary.txt`. Nobody
should be able to read it through an upload. A crafted MATLAB file can: uploaded
with a declared content type of `image/png`, which Rails keeps without looking,
it reaches libvips' `matload`, whose HDF5 storage points at the private file.
The resized "image" that comes back holds the file's bytes.

The case began as a question, CIT-294: run one pinned Rails/libvips/libmatio/HDF5
configuration against three arms. The unblocked MATLAB canary discloses the
private file. The blocked one refuses the path, and *a generic crash alone is
insufficient*. An ordinary PNG control keeps working. That is historical issue
text, not a sealed declaration: nothing was registered before the run.

| Arm | `VIPS_BLOCK_UNTRUSTED` | Loader | Private file opened | Bytes returned |
| --- | --- | --- | --- | --- |
| MAT canary | unset | `matload` | **yes** | the file, byte-exact |
| MAT canary | `1` | refused, `matload: operation is blocked` | **no** | none |
| PNG control | unset | `pngload` | n/a | unchanged |
| PNG control | `1` | `pngload` | n/a | unchanged |

Alice ran the four arms live under `strace` and wrote a Pkl checker over what
they recorded. Her pull request, #117, is the commit in the **Client**: its
subject is the question this lesson asks, and its body is her description,
quoted. Her checker passes.

Select **Solve** for Bob's review. The grey line below the commit is his first
question, which he answered by editing the recorded evidence in a copy and
running Alice's checker again: he forged a read of the private file into the
blocked arm's trace. Press **Tab** to accept it.

Open the lens above the accepted line. Peek opens the edit itself, the trace as
Bob left it, beside the review's own words and the checker's result. The
result is a **reproduction**: Bob's edit, run again for real against Alice's
checker as submitted, because the review's own runs were not kept.
The forged read still left all 28 assertions passing.
