# Does the check require a real read of the private file?

Her checker now counts a read of the private file only if the trace shows a
successful `openat` of its exact path, and every arm's trace must show its own
upload being opened, so an empty trace is no longer taken as proof that nothing
was read. She says each of review 3's edits now fails the suite.

bring back: it brings back the checker itself, asked every question Bob asked
of the three commits before it, word for word, each against what Alice
claimed. The pending line in the **Agent** names Pkl, not Bob, and the reply
says plainly that no review was recorded.

got. Whether it is the right answer is a question for the next reviewer.
