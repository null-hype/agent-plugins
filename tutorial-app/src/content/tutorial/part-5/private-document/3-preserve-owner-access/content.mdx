# Can Bob still read his own document?

Denying every request would block Alice too. The final question checks that the
owner’s legitimate access still works after the policy change.

The Agent report starts on Bob’s recorded request. Select **HTTP observation**:
the request identifies Bob and the response is **200**, with his own document.
The Client editor retains the earlier reproduction and prevention diagnostics.

Press **Solve** to reveal the final **98%** score, then inspect its expected range
and evidence. All three questions now have recorded evaluations: reproduce the
flaw, prevent the demonstrated exploit, and preserve the tested owner-read flow.

The Pkl contract defines the questions, their dependencies, and expected ranges.
Playwright collects evidence in that order inside Dagger; Jev scores it; the
comparison checks the observed results against those expectations. This lesson
replays those artifacts. The passing results apply to these collected observations,
not every possible authorization behavior.
