# Does the owner check keep the document private?

The patched commit changes one thing: the policy lets a signed-in user read a
document only if they own it. Unfold the commit to read it.

The questions are the ones asked of the baseline, word for word. Select **Solve**
to ask Jev, and take either suggestion with **Tab** (or **Alt+]** to switch first),
or both. The **Agent** terminal holds back each finding until you accept it.

Open the lens above an accepted line and compare the exchange with the baseline's:
the request is the same, and only the policy changed. These answers cover
this one route and these two readers, not every way a document can be reached.
