# Can Alice read Bob’s private document?

The baseline policy allows every request. Alice is signed in, but the private
document belongs to Bob. In the Agent pane, select **HTTP observation** and inspect
the request and response. Does this reproduce broken object-level authorization?

The Client editor identifies the captured snapshot and question. The Agent report
shows the evidence and the expected score range from the Pkl question contract.
**Not scored** means this replay has not revealed the recorded evaluation yet.

Press **Solve** to reveal Jev’s recorded **96%** score. Its diagnostic appears in
the Client editor, and the Agent report adds the result and model identity.
Select the diagnostic to inspect the supporting evidence and expectation.

running Playwright. Solve replays that run; it does not execute tests or call Jev.

an assessment of the supplied evidence for this question, not proof of general
