A change passes its check. A reviewer asks a plain question of it:
can an upload read a private file on the server?

What does the passing check actually tell you about the answer?

**[Start the review →](/part-5/can-an-upload-read-a-private-file/1-can-the-check-tell-a-real-read-of-the-private-file-from-a-forged-one)**

In four turns, follow one recorded review: three pull requests that each said
the check was now sound, and the reviews that each found it was not. The author
claims; the reviewer edits the recorded evidence and runs the author's own
checker again. Each finding stays hidden until you accept the question, and each
one opens onto the evidence: the record the reviewer changed, the review's own
words, and the checker's result.

This research prototype explores how to make agent decisions reviewable: for
each claim, the check that was run and the evidence you can inspect yourself.

**How to follow the review:** choose **Solve** to ask the reviewer, **Tab** to
accept a suggested question, then the **→** arrow to continue. Each part is a
session; each lesson is a turn.
