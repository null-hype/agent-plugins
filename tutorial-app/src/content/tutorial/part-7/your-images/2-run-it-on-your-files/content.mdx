# Run it on your files

From the repository's `tutorial-app` directory:

```sh
npm ci
npm run image-claims -- /path/to/downloaded-image.png /path/to/drawing.svg
```

The command reads local bytes without rendering the files. Exit status is
`0` for no findings, `1` for findings, and `2` for a usage or read error.

For the lesson's examples and reproducibility check:

```sh
npm run image-claims -- src/stories/fixtures/image-claims/rails-canary.png src/stories/fixtures/image-claims/control.png
npm run image-claims:check
npm run image-claims:render
```

The first command should report the canary and exit `1`. The second runs the
regressions and checks the displayed panel against a fresh execution; the third
regenerates it after an intentional change.
