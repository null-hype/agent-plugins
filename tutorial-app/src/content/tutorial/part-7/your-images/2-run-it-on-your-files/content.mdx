# Run it on your files

You need git and Node.js 22. Get the checker and its dependencies:

```sh
git clone https://github.com/null-hype/agent-plugins
cd agent-plugins/tutorial-app
npm ci
```

Run it on two of the folder's files, the canary and the local control:

```sh
npm run image-claims -- src/stories/fixtures/image-claims/rails-canary.png src/stories/fixtures/image-claims/control.png
echo $?
```

You should see the canary's two findings from the previous lesson and nothing
for the control. The exit status is `1` because there are findings: `0` means
none, `1` means at least one, and `2` means a usage or read error. A `1` here
is the expected result, not a failure of the tool.

Now substitute your own files, for example ones downloaded from a shared
folder:

```sh
npm run image-claims -- /path/to/downloaded-image.png /path/to/drawing.svg
```

The command reads the files locally without rendering them or passing them
to an application's image loader, and it does not upload them.
