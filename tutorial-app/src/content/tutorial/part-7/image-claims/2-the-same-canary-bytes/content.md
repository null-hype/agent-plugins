# Start with the Rails canary

In the Rails/MATLAB investigation, an upload declared `image/png` reached
libvips' MATLAB loader. That loader and matio interpreted different parts of
the same header differently. The resulting HDF5 read returned bytes from a
test-owned dummy file through a Rails image variant.

We start with **the same canary bytes**, regenerated by that investigation's
`craft_mat_canary.py`. Their SHA-256 matches both retained MATLAB runs:
`f1c62ebc5fb7ab50655d505f3c30498713cdef232d3bdef585935024bd007fcc`.
Renaming the file `rails-canary.png` changes neither its bytes nor that identity.
