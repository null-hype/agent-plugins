These labs explore how a declared rule becomes an executable check.
They move from a small vocabulary exercise to approval records and reconciliation.

For the client walkthrough, [start with Budget Authority](/part-3/proposal-p-against-the-budget/1-jev-types-the-answer).
You can return here to edit the inputs and inspect the implementation.

- **Vocabulary:** distinguish a well-formed term from one admitted by a policy.
- **Authorization:** inspect a mocked trace whose security rule compares an authorization subject with user-controlled input.
- **Reconciliation:** compare a worker's request, a supervisor's grant, and an observed operation.

The language exercises use deliberately narrow lesson policies. They illustrate
how constraints work; accepting a word or repairing a sentence does not establish
that an API is secure.

Browser exercises use TypeScript evaluators and fixtures. Where a Pkl source or
recorded run supports a lesson, the lesson identifies it and explains its scope.
