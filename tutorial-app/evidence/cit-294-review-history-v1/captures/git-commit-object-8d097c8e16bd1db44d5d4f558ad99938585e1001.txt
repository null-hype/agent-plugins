CIT-297: strengthen CIT-294 evidence validation per review

Fixes four gaps CIT-297's review found in the CIT-294 checker, each
reproduced and independently re-verified fixed against the real
observations/*.json (not just inline Pkl literals):

1. The independent strace evidence never reached Pkl. Deleting the trace,
   or forging a dummy-file read into the blocked arm, still passed all 28
   assertions. run_arms.sh now derives independent_dummy_file_openat_count
   (plus source/image identity and the live load_defaults/variant_processor
   config) entirely outside canary_runner.rb's own process, merges it into
   each arm's JSON, and Reconcile.pkl checks it against Claims.pkl's
   independentReadExpected.

2. A generic crash (e.g. RuntimeError: disk full) passed as a successful
   block, because the check read the preliminary loader-probe's
   loader_error instead of the actual variant call's own error.
   Reconcile.pkl now requires the real variant_error_class/variant_error to
   match the claimed refusal specifically.

3. matches_dummy_file was trusted as a boolean with no validation of the
   underlying bytes -- emptying the hex/count, or corrupting the blocked
   PNG control's pixels, still passed. Reconcile.pkl now checks
   returned_bytes_hex/returned_byte_count directly against pinned expected
   values in Claims.pkl, plus a dedicated check that the raw bytes and the
   self-reported boolean agree.

4. No actual detector output or authoritative check result was retained --
   only prose narrating "8 facts / 28 asserts passing". Added diagnose.pkl
   (Reconcile.check's flags per arm, written to reports/diagnostics.json,
   following noteexpand's diagnostics.json pattern) and wired
   `pkl test --junit-reports` into run_arms.sh, committing the real JUnit
   result to reports/cit294.test.xml.

cit294.test.pkl gained eight negative-control facts covering the review's
five exact mutations plus the two direct-Reconcile.check attacks it named;
all are now flagged. Suite: 18 facts / 56 asserts / 4 examples, 100% pass,
re-run against the same already-built, already-proven cit294:live image
(no rebuild needed).
