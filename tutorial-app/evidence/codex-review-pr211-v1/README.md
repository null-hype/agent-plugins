# A recorded Codex review (PR #211)

`review.json` is one `codex review --base main` run, cut down from its rollout
transcript (session `01a14829-4e11-72e0-ac83-c37d80f6365e`) to what
`codex-review-sync.sh` reads: `session_meta`'s id, cwd and git, the
`EnteredReviewMode` target, and the `ExitedReviewMode` review output. The
transcript's instructions and command outputs are left out.

`codex-review-sync.sh` is the reviewed file at the reviewed commit (`640327f`),
which is what the findings' line ranges refer to.

Rendered by `src/stories/CodexReview.stories.tsx`; the same review is posted at
https://github.com/null-hype/agent-plugins/pull/211.
